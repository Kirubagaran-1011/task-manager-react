# Task Manager Web App

A responsive single-page task manager built with React functional components and Hooks.

## Features
- Add, edit (double-click), complete and delete tasks
- Filter by All / Active / Completed
- Tasks are saved in the browser (localStorage), so they remain after refresh
- Mobile-first responsive layout using CSS3 Flexbox

## Tech Stack
React.js, JavaScript (ES6), HTML5, CSS3, Vite, Git

## Hooks used
- `useState` for tasks, input text, filter and edit state
- `useEffect` to sync tasks to localStorage

## Run locally
```bash
npm install
npm run dev
```
Open `http://localhost:5173`.
